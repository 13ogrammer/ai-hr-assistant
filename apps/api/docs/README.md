## Key Policy Information at a Glance

### Leave Entitlements Summary

| Leave Type | Entitlement | Accrual | Payment |
|---|---|---|---|
| Annual Leave | 4 weeks/year | Continuous, pro-rata | Ordinary rate + any loading |
| Personal/Sick | 10 days/year | Continuous, pro-rata | Ordinary rate |
| Long Service Leave | 8.67 weeks per 10 years | Continuous | Ordinary rate + 17.5% loading |
| Maternity Leave | 12 weeks paid | N/A (after 12 months service) | Ordinary rate |
| Paternity Leave | 2 weeks paid | N/A (after 12 months service) | Ordinary rate |
| Adoption Leave | 3 weeks paid | N/A (after 12 months service) | Ordinary rate |
| Parental Leave | Up to 12 weeks unpaid | N/A | Unpaid (optional voluntary contributions) |
| Bereavement | 3-5 days paid | N/A | Ordinary rate |

### Remuneration Summary

| Component | Details |
|---|---|
| Pay Frequency | Fortnightly (26 pay periods/year) |
| Pay Method | Direct bank transfer |
| Base Salary | As per employment contract, reviewed annually |
| Superannuation | 11.5% employer contribution (Industry Super default) |
| Tax Withholding | PAYG withheld based on TFN declaration |
| Bonuses | Discretionary, typically 0-15% based on performance |
| Professional Development | $1,500-$3,000 per employee annually |

## How to Use This Documentation

### For Employees

1. **First time:** Start with Employee Handbook (10_EMPLOYEE_HANDBOOK.md) for overview
2. **Specific questions:** Use the policy index above to find relevant policy
3. **Clarifications:** Contact your manager or HR department
4. **Issues/concerns:** Follow the grievance procedure in Code of Conduct

### For Managers

1. **Policy reference:** Use specific policy document as needed
2. **Employee management:** Consult HR on policy interpretation
3. **Process follow-up:** Use documented procedures for consistency
4. **Updates:** Alert team to any policy changes

### For HR Department

1. **Policy administration:** Primary reference for all HR procedures
2. **Decision-making:** Ensure consistency with documented policies
3. **Training:** Use documentation to train managers and employees
4. **Continuous improvement:** Review feedback and update as needed
